The measurement was sound; generalising from "the bot cannot clone this" to "a runner cannot" was not, and it was made without checking how Actions authenticates. **The real AC7 constraint is narrower**: `AllowedCrossRepoIDs` is empty by default, so a workflow cannot check out a *different* private repository on the instance, and cross-repo access is denied outright for fork pull requests.
